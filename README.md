# 罗根音乐（发现音乐）
作者：罗根
一款安卓本地+在线音乐播放器，采用毛玻璃拟态UI设计。

## ✨ 功能特点
- 在线搜索音乐，支持播放在线音源
- 自动扫描手机本地音乐、本地视频播放
- 无歌曲封面时自动加载默认封面，支持自定义上传歌曲封面
- 封面样式切换：方形 / 圆形 / 沉浸式全屏毛玻璃封面
- 歌词同步显示，沉浸式歌词页面
- 听歌识曲功能
- 一起听：多人同步播放同一首歌曲
- 支持将歌曲设置为手机铃声
- 流畅的播放控制：上一曲 / 下一曲 / 暂停、迷你播放栏、通知栏播放控件

## 📱 运行环境
安卓 8.0 及以上

## 📦 编译说明
1. 下载本项目源码
2. 使用 AndroidIDE / AIDE / Android Studio 打开项目
3. 同步 Gradle，直接编译打包 APK
> 本项目不含签名keystore，编译时请自行生成签名文件
